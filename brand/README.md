# thunderstruck brand assets

Chosen mark: **past the limit**. It shows an amplifier's level meter whose needle is a
lightning bolt. The needle is pegged past the red zone and pivots on Claude's spark.

The idea is the one behind cctop's mark: the tool's function fused with its name, in
Claude terracotta. thunderstruck's mark merges three things:

- **What thunderstruck does.** It finds where load pushes code past what it was
  built to take. It ranks fracture points by churn × complexity × missing stability
  patterns. Claude then reads the flagged code and its history and returns
  falsifiable failure hypotheses with resolved evidence. The meter is that risk
  gauge, read past its limit.
- **The name.** A strike of lightning, and a dial turned past the top of its range:
  the lightning is the needle.
- **Claude.** Its terracotta, and its warm burst of rounded rays as the pivot.

All geometry is original, with no copy of Anthropic's mark.

Palette, shared with cctop so the two read as one family:

- terracotta `#D97757` (needle, red zone, spark)
- tick ink `#111111` on light grounds and `#D6DEE8` on dark grounds
- charcoal `#0E1318`
- paper `#F1F3F6`
- text `#1A212C`

The wordmark is IBM Plex Sans Condensed Bold converted to outlines (fonts in
`fonts/`, SIL OFL), so no SVG depends on an installed font.

Rebuild everything. fontkit and sharp come from `studio-master`, as for cctop:

```bash
cd ../studio-master && NODE_PATH=$PWD/node_modules ./node_modules/.bin/tsx ../thunderstruck/brand/build.ts
```

`contact-sheet.png` shows the whole set on light and dark grounds. Every file in
`svg/` and `png/` is generated by `build.ts`, so change the script and rebuild
rather than editing an output.
